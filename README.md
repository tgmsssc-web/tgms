# TG Model School & Junior College Website

## Files
- `index.html` — main homepage
- `style.css` — responsive website styling
- `logo.png` — TG Model School & Junior College logo

## GitHub Pages
1. Create/open your GitHub repository.
2. Upload these three files to the repository root.
3. Make sure the homepage is named exactly `index.html`.
4. Go to **Settings → Pages**.
5. Select **Deploy from a branch**, choose your main branch and `/ (root)`.
6. Save and open the generated GitHub Pages URL.
